# docs-master expert playbook

Read before Phase 2 and before delegating to any child. On conflict this file beats the child. Copy its gate additions into SPEC.md Done-when.

**Which tool for which need**
| Need | Use | Not |
|---|---|---|
| Editable deck (default) | pptx skill + theme-factory (contrast-checked) + dataviz for charts | wowerpoint |
| Illustrated narrative deck from one finished doc, explicitly requested | wowerpoint (warn first: it uploads the doc to Google and outputs a non-editable PDF) | executive decks |
| Report, proposal, spec, memo | doc-coauthoring, then docx or pdf | free-form dumping |
| Status, 3P update, newsletter, FAQ | internal-comms | invented metrics |
| Incident report | internal-comms with the incident template below | |
| Spreadsheets, PDF operations | xlsx, pdf skills | |

**Patches when using children**
- doc-coauthoring: before drafting, write the governing thought (answer + so-what) and an SCQA paragraph and get approval; draft the executive summary first as a hypothesis, build 3 non-overlapping support points, rewrite the summary last. Finish with a headings-only read-through by a fresh subagent and a claim trace.
- Incident template: Impact (who, how long) · Timeline (UTC) · Root cause · What went well · Action items (owner, date). Blameless; summary in the first 3 lines.
- Decision memo: bottom line up front · options · recommendation · risks · ask.
- theme-factory: on Windows map DejaVu/Free fonts to Segoe UI, Calibri or Georgia (or embed fonts); run a WCAG contrast check (4.5:1 body, 3:1 large text) before applying; treat Ocean Depths teal-on-navy as large-text only; add a 6-colour categorical and a sequential chart palette.
- Charts (Tufte): maximise data-ink, no 3-D, direct labels, small multiples over dual axes. Slides (Duarte): one idea each, the audience as hero, tension then resolution, one clear call to action.
- Accessibility: alt text, logical reading order, 4.5:1 contrast, 18pt+ body text on slides, tagged PDF. Render every output to PDF/PNG and inspect each page.

**Best-of-best sources to require**: Minto *The Pyramid Principle* · Duarte *slide:ology* and *Resonate* · Tufte *The Visual Display of Quantitative Information* · Knaflic *Storytelling with Data* · digital.gov plain language · WCAG 2.2 · Microsoft and Google developer style guides · Diátaxis (technical docs) · NN/g reading research · FT Visual Vocabulary.
